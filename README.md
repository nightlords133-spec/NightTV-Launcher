# NightTV — оболочка для Android TV

Автор: **NightLord РВЕ**

Свой домашний экран для приставок на Android TV / Google TV (Android 5.1+).

## Что умеет

- Крупные часы и дата.
- Погода по названию города (Open-Meteo, без ключей и регистрации).
- Ряд **избранного** сверху с ручной перестановкой.
- Сетка **всех приложений** (ТВ-баннеры, если у приложения есть, иначе иконка).
- Управление только пультом: подсветка и увеличение плитки в фокусе.
- 5 тем: Ночь, Океан, Лес, Закат, Графит; 4–7 колонок в сетке.
- Меню приложения: открыть, в избранное, сдвинуть, «О приложении», удалить.
- Список обновляется сам при установке и удалении приложений.

## Управление

| Кнопка пульта | Действие |
|---|---|
| ОК | Открыть приложение |
| Удерживать ОК или «Меню» | Меню приложения (избранное, порядок, удаление) |
| «Домой» / «Назад» | Вернуться к началу экрана |
| ⚙ Настройки (вверху справа) | Тема, колонки, город, системные настройки |

## Как получить APK

### Вариант 1. Через GitHub (без установки Android Studio)

1. Создайте пустой репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится сама (или нажмите **Run workflow**).
3. Через 3–5 минут в завершённой сборке скачайте артефакт **NightTV-Launcher** — внутри `NightTV-Launcher.apk`.

### Вариант 2. На своём компьютере (Windows)

1. Установите Android Studio.
2. Откройте папку проекта, дождитесь синхронизации Gradle.
3. Build → Build APK(s), или в терминале: `gradlew.bat assembleDebug`
4. Файл: `app\build\outputs\apk\debug\app-debug.apk`

## Установка на приставку

Через ADB по сети (на приставке включить «Для разработчиков» → «Отладка по сети»):

```
adb connect IP_ПРИСТАВКИ
adb install NightTV-Launcher.apk
```

Или скопировать APK на флешку и открыть через файловый менеджер на приставке.

## Как сделать NightTV главным экраном

На обычных Android-боксах после установки нажмите «Домой» и выберите NightTV → «Всегда».

На **Android TV / Google TV** система не даёт выбрать сторонний домашний экран.
Варианты:

**А. Отключить стандартный лаунчер через ADB** (обратимо):

```
adb shell pm list packages | findstr launcher
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

Для Google TV пакет обычно `com.google.android.apps.tv.launcherx`
(иногда также `com.google.android.tungsten.setupwraith`).
Вернуть стандартный экран:

```
adb shell pm enable com.google.android.tvlauncher
```

> На некоторых прошивках после отключения стандартного лаунчера перестаёт работать
> часть системных функций (например, поиск голосом с главного экрана, рекомендации).
> Если что-то сломалось — просто включите его обратно командой `pm enable`.

**Б. Без ADB:** поставить приложение-переназначатель кнопок (например, Button Mapper)
и назначить кнопке «Домой» запуск NightTV.
